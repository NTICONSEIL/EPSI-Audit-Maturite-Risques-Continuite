## Méthode pédagogique

1. Identifier le référentiel et les critères.
2. Recueillir les preuves.
3. Coter la maturité en justifiant chaque note.
4. Cartographier les risques et évaluer la continuité.
5. Présenter un rapport et un plan de remédiation.
