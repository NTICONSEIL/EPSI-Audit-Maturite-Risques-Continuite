# Sources et limites

- Directive NIS2 : https://eur-lex.europa.eu/eli/dir/2022/2555/oj/fra
- Règlement DORA : https://eur-lex.europa.eu/eli/reg/2022/2554/oj/fra
- ANSSI / EBIOS Risk Manager : https://cyber.gouv.fr/la-methode-ebios-risk-manager
- NIST CSF 2.0 : https://www.nist.gov/cyberframework
- ISO 27001 : https://www.iso.org/standard/27001
- ISO 22301 : https://www.iso.org/standard/75106.html

Les normes ISO sont généralement protégées par le droit d’auteur : les fiches en résument les principes sans reproduire les textes normatifs. Les obligations de NIS2 doivent être appréciées à la lumière de la transposition nationale applicable.
